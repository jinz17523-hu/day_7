# C 语言扫雷游戏知识点总结

这份文档总结了本次扫雷游戏中使用到的主要 C 语言知识，并解释连片展开、标记雷、计时和胜利判定的基础原理。

## 一、项目文件的分工

项目分为三个文件：

| 文件 | 作用 |
| --- | --- |
| `game.h` | 保存宏定义、库函数头文件和函数声明 |
| `game.c` | 实现棋盘初始化、显示、布雷、排查和标记等功能 |
| `test.c` | 提供菜单和 `main` 函数，负责启动游戏 |

这种写法叫做**模块化编程**。它把声明、功能实现和程序入口分开，使代码更容易阅读、修改和复用。

---

## 二、宏定义

```c
#define row 9
#define col 9
#define mine_count 10

#define rows (row + 2)
#define cols (col + 2)
```

宏定义可以给固定数据起一个有意义的名字。

- `row` 和 `col` 表示玩家看到的棋盘大小。
- `mine_count` 表示雷的总数。
- `rows` 和 `cols` 比实际棋盘多两行、两列，用来增加一圈边界。

实际的 `9 × 9` 棋盘使用下标 `1` 到 `9`，外面保留一圈不显示的区域。这样统计周围八个位置时，不容易访问到数组范围之外。

例如，检查 `(1, 1)` 周围时，程序仍然可以访问第 `0` 行和第 `0` 列。

---

## 三、二维数组表示棋盘

```c
char mine[rows][cols];
char show[rows][cols];
```

程序使用两个二维字符数组保存不同的信息：

### `mine` 数组

保存真正的雷区：

- `'0'`：不是雷。
- `'1'`：是雷。

### `show` 数组

保存玩家当前看到的棋盘：

- `'*'`：还没有排查。
- `'F'`：玩家标记为可能有雷。
- `'0'` 到 `'8'`：该位置周围雷的数量。

把真实棋盘和显示棋盘分开，可以防止玩家直接看到雷的位置。

---

## 四、棋盘初始化

```c
void initboard(char board[rows][cols], int a, int b, char set)
{
    int x = 0;
    int y = 0;

    for (x = 0; x < a; x++)
    {
        for (y = 0; y < b; y++)
        {
            board[x][y] = set;
        }
    }
}
```

二维数组需要使用两层循环：

1. 外层循环遍历每一行。
2. 内层循环遍历这一行中的每一列。

初始化时：

```c
initboard(show, rows, cols, '*');
initboard(mine, rows, cols, '0');
```

显示棋盘全部设为 `'*'`，真实雷区全部设为 `'0'`。

## 五、随机布雷

```c
int x = rand() % a + 1;
int y = rand() % b + 1;
```

`rand()` 用来产生随机数。

`rand() % a` 的结果范围是 `0` 到 `a - 1`，再加 `1` 后，范围就变成 `1` 到 `a`，正好对应有效棋盘坐标。

布雷前需要判断当前位置是否已经有雷：

```c
if (board[x][y] == '0')
{
    board[x][y] = '1';
    count--;
}
```

只有空位置才能放雷，这样可以避免同一个坐标重复布雷。

程序开始时还需要设置随机数种子：

```c
srand((unsigned int)time(NULL));
```

如果不设置种子，程序每次运行时产生的雷区可能完全相同。

---

## 六、统计一个位置周围的雷

一个位置周围最多有八个相邻位置：

```text
左上   上   右上
左    当前   右
左下   下   右下
```

程序使用两层循环遍历这八个方向：

```c
for (dx = -1; dx <= 1; dx++)
{
    for (dy = -1; dy <= 1; dy++)
    {
        if ((dx != 0 || dy != 0) && mine[x + dx][y + dy] == '1')
        {
            count++;
        }
    }
}
```

`dx` 和 `dy` 表示相对于当前位置的偏移量。

当 `dx == 0` 且 `dy == 0` 时，表示当前位置本身，因此需要跳过。

---

## 七、字符和数字之间的转换

棋盘是 `char` 类型，所以数字需要转换成字符后才能显示：

```c
show[x][y] = (char)(count + '0');
```

在字符编码中，字符 `'0'` 到 `'9'` 是连续排列的。

例如：

```text
0 + '0' 得到字符 '0'
1 + '0' 得到字符 '1'
8 + '0' 得到字符 '8'
```

这里保存的是字符，而不是整数。

---

## 八、空白区域自动展开

当玩家排查的位置不是雷，并且周围雷数为 `0` 时，说明它附近比较安全。程序会继续排查周围位置，直到遇到周围有雷的数字格子。

这个功能使用了**递归**。

```c
static void expand_blank_area(
    char mine[rows][cols],
    char show[rows][cols],
    int x,
    int y,
    int a,
    int b)
```

递归就是函数在满足条件时调用自己。

### 递归展开的主要步骤

1. 检查坐标是否在棋盘范围内。
2. 检查该位置是否已经展开或已经标记。
3. 检查该位置是否为雷。
4. 计算周围雷的数量并显示。
5. 如果周围雷数为 `0`，继续处理周围八个位置。

### 递归必须有结束条件

```c
if (x < 1 || x > a || y < 1 || y > b)
{
    return;
}

if (show[x][y] != '*' || mine[x][y] == '1')
{
    return;
}
```

这些判断非常重要。它们可以防止：

- 坐标越界。
- 已展开的位置被重复处理。
- 程序进入无限递归。
- 自动展开时错误地打开雷。

### 连片展开的效果

如果多个相邻位置周围都没有雷，它们会形成一片自动展开的区域。区域边缘会显示数字，提醒玩家附近有多少个雷。

---

## 九、标记和取消标记

程序给玩家提供两种操作：

```text
1. 排查
2. 标记或取消标记
```

标记时，把 `'*'` 改成 `'F'`：

```c
show[x][y] = 'F';
```

取消标记时，把 `'F'` 改回 `'*'`：

```c
show[x][y] = '*';
```

标记只是玩家做出的判断，并不会改变真正的 `mine` 数组。

为了防止误操作，排查一个已经标记的位置时，程序会要求玩家先取消标记。

## 十、游戏计时

游戏开始时记录时间：

```c
time_t start_time = time(NULL);
```

需要显示时间时，再获取当前时间：

```c
long elapsed = (long)difftime(time(NULL), start_time);
```

`difftime` 用来计算两个时间之间相差的秒数。

计时原理可以表示为：

```text
已用时间 = 当前时间 - 游戏开始时间
```

程序在每次等待玩家操作前显示当前用时，并在胜利或失败时显示总用时。

## 十一、胜利判定

扫雷游戏不需要玩家一定标对所有雷。只要所有非雷位置都已经展开，就可以判定胜利。

程序遍历显示棋盘，统计仍然没有打开的位置：

```c
if (show[x][y] == '*' || show[x][y] == 'F')
{
    unopened++;
}
```

如果没有打开的位置数量等于雷的总数，说明所有安全位置都已经排查完成：

```c
return unopened == mine_count;
```

这种判断方式允许玩家：

- 标记真正的雷。
- 不标记雷，只展开全部安全位置。
- 存在错误标记时继续排查并纠正。

## 十二、输入检查

`scanf` 会返回成功读取的数据数量。

```c
if (scanf("%d%d", &x, &y) != 2)
{
    printf("输入无效，请输入两个数字。\n");
}
```

如果玩家输入字母或其他错误内容，读取就会失败。失败后需要清空输入缓冲区，否则错误内容会一直留在缓冲区中，导致程序反复读取失败。

```c
static void clear_input_buffer(void)
{
    int ch = 0;

    while ((ch = getchar()) != '\n' && ch != EOF)
    {
    }
}
```

此外，还要检查输入坐标是否在有效范围内：

```c
if (x < 1 || x > a || y < 1 || y > b)
{
    printf("坐标超出棋盘范围，请重新输入。\n");
}
```

## 十三、`static` 函数

部分辅助函数前面使用了 `static`：

```c
static int getminecount(...);
static void expand_blank_area(...);
static int is_win(...);
```

在源文件中给函数加上 `static`，表示这个函数只在当前 `.c` 文件中使用。

这样做可以：

- 隐藏内部实现细节。
- 避免和其他源文件中的同名函数冲突。
- 让程序的模块边界更加清楚。

## 十四、程序整体流程

```text
启动程序
   ↓
显示菜单
   ↓
初始化真实棋盘和显示棋盘
   ↓
随机布置雷
   ↓
记录开始时间
   ↓
玩家选择排查或标记
   ↓
排查到雷？ ── 是 ──→ 游戏失败并显示总用时
   │
   否
   ↓
周围没有雷？ ── 是 ──→ 递归展开周围区域
   │
   否
   ↓
显示周围雷数
   ↓
所有安全位置都已打开？ ── 是 ──→ 游戏胜利并显示总用时
   │
   否
   └────────────────────→ 继续游戏
```

## 总结

扫雷项目虽然规模不大，但综合使用了 C 语言中的数组、函数、循环、分支、递归、随机数和时间处理等基础知识。

其中最重要的设计思想是：

- 使用 `mine` 保存真实数据，使用 `show` 保存玩家看到的数据。
- 使用周围八个方向的偏移量统计雷数。
- 使用递归完成空白区域的连片展开。
- 使用状态字符 `'*'`、`'F'` 和 `'0'` 到 `'8'` 管理格子状态。
- 使用开始时间和当前时间的差值计算游戏耗时。

掌握这些原理后，可以继续尝试增加难度选择、第一次排查必定安全、剩余雷数显示、排行榜和图形界面等功能。
